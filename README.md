## 📖 About
Easily merge hundreds of MP4 video files with their matching SRT subtitle files instantly. This application fully leverages MKVToolNix for lossless, high-speed muxing, making batch processing incredibly simple and fast.

## 🚀 How to Use
1. **Prerequisite:** Download and install the official [MKVToolNix](https://mkvtoolnix.download/) software (this tool uses it under the hood).
2. **Download App:** Go to the **[Releases](../../releases/latest)** tab and download the latest executable.
3. **Run:** Double-click the downloaded `.exe` file (no installation required).
4. **Enjoy:** Select your video/subtitle folders and click Mux!

<br>

## ✨ Features
- **Batch Processing:** Seamlessly pair and mux entire directories of media files in one click.
- **Lossless Speed:** Uses MKVToolNix under the hood to ensure zero quality degradation and lightning-fast speeds.
- **Master-Detail UI:** A clean, native interface built on PyQt6 to easily review your pairs before muxing.
